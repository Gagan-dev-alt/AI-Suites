# AI Suites Plan

This directory contains the concrete planning files for building AI Suites.

Read in this order:

1. `RESEARCH.md` - product and technology research.
2. `ROADMAP.md` - phased development plan.
3. `MVP_SCOPE.md` - what the first usable version must include.
4. `ARCHITECTURE.md` - monorepo, app, backend, database, auth, and AI provider shape.
5. `ENVIRONMENT.md` - required environment variables and API keys.
6. `IMPLEMENTATION_CHECKLIST.md` - build checklist for agents.

Primary build rule: do not start the dev server unless the user explicitly asks. The user will run it manually.
